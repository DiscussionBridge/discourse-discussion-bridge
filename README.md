# DiscussionBridge for Discourse

Use your Discourse forum to host discussions for articles across your websites.
The plugin also lets your team publish selected forum topics to connected sites
and bring articles from those sites back to the forum.

1. Install DiscussionBridge on your Discourse site.
2. In the DiscussionBridge admin area, add a Content Connection for the site
   you want to connect.
3. Choose which content can publish and which direction it can go.

Use Bridge Records in Discourse to see which articles and topics are linked.
